# টেলিগ্রাম গ্রুপ বট + চ্যানেল পোস্ট সিস্টেম

## ফিচার
- Welcome / Goodbye মেসেজ (কাস্টমাইজযোগ্য), নিচে অপশনাল বাটন সহ (যেমন "Video Channel")
- /warn → ৩ বার হলে অটো ব্যান
- /ban, /unban (গ্রুপ এডমিনদের জন্য)
- গ্রুপে লিংক/ফরোয়ার্ড/প্রোমো মেসেজ পাঠালে অটো ডিলিট + ওয়ার্নিং + গ্রুপ রুলস দেখানো
- /ad → শুধু ADMIN_ID (5140546628) এর জন্য অ্যাডমিন প্যানেল খুলবে (ইনলাইন বাটন)
- **চ্যানেল পোস্ট সিস্টেম** — ভিডিও/ফটো + সর্বোচ্চ ৪টা কাস্টম বাটন সহ চ্যানেলে পোস্ট করা

## চ্যানেল পোস্ট সিস্টেম — ব্যবহার
1. প্রথমে বট কে আপনার চ্যানেলে **Admin** বানান (Post Messages পারমিশন সহ)
2. প্রাইভেট চ্যাটে বট কে `/post` পাঠান (বা `/ad` প্যানেল থেকে "📢 চ্যানেলে নতুন পোস্ট বানান")
3. প্রথমবার চ্যানেল সেট করতে বলবে — চ্যানেলের ইউজারনেম (`@mychannel`) বা numeric ID পাঠান (একবার সেট করলে মনে রাখবে, `/ad` → "🎯 পোস্ট চ্যানেল পরিবর্তন" দিয়ে বদলানো যাবে)
4. ভিডিও বা ছবি পাঠান (ক্যাপশনসহ পাঠাতে পারেন)
5. বট একটা প্রিভিউ দেখাবে সাথে বাটন:
   - **➕ বাটন যোগ করুন** → চাপলে `বাটন নাম | লিংক` ফরম্যাটে পাঠাবেন, যেমন: `Watch Now | https://t.me/yourchannel` — সর্বোচ্চ ৪টা বাটন যোগ করা যাবে
   - প্রতিটা যোগ করা বাটনের পাশে ❌ চাপলে সেটা মুছে যাবে
   - **✅ চ্যানেলে পোস্ট করুন** → ফাইনাল পোস্টটা চ্যানেলে পাঠিয়ে দিবে (বাটন সহ)
   - **❌ বাতিল করুন** → পুরো ড্রাফট বাতিল
6. যেকোনো সময় বাতিল করতে `/cancel` লিখুন

## Welcome/Goodbye বাটন সেট করা
`/ad` প্যানেলে "🔘 Welcome/Goodbye বাটন সেট" চাপুন, তারপর এই ফরম্যাটে পাঠান:
```
Video Channel | https://t.me/yourchannel
```
বাটন বন্ধ করতে পাঠান: `off`

## গ্রুপ রুলস সেট করা
`/ad` প্যানেলে "📜 গ্রুপ রুলস সেট" চাপুন, তারপর রুলসের টেক্সট পাঠান। এরপর থেকে কেউ ওয়ার্নিং খেলে সেই মেসেজের নিচেই রুলসটা দেখাবে। বন্ধ করতে পাঠান: `off`

## Render এ ডিপ্লয় (Web Service — ফ্রি)
1. render.com এ লগইন করুন
2. New → Web Service → আপনার GitHub রিপো কানেক্ট করুন
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python bot.py`
   - Instance Type: **Free**
3. Environment ভ্যারিয়েবল সেট করুন:
   - `BOT_TOKEN` → @BotFather থেকে পাওয়া টোকেন
   - `ADMIN_ID` → 5140546628 (আগে থেকেই render.yaml এ আছে)
4. Deploy চাপুন

⚠️ **ফ্রি Web Service এর সীমাবদ্ধতা:** ১৫ মিনিট কোনো HTTP রিকোয়েস্ট না পেলে Render সার্ভিসটা "spin down" করে দেয়। এটা এড়াতে UptimeRobot (ফ্রি) দিয়ে প্রতি ৫ মিনিটে আপনার Render URL এ পিং করান — bot.py তে `/` হেলথ এন্ডপয়েন্ট আগে থেকেই আছে।
সম্পূর্ণ নিশ্চিত uptime চাইলে Background Worker ($7/month) সবচেয়ে ভরসাযোগ্য।

## BotFather এ সেটিংস
- বট কে গ্রুপে অ্যাড করুন, Admin বানান (ব্যান/মেসেজ ডিলিট পারমিশন সহ)
- বট কে আপনার চ্যানেলেও Admin বানান (Post Messages পারমিশন সহ) — পোস্ট সিস্টেমের জন্য দরকার
- গ্রুপে Privacy Mode অফ করুন: @BotFather → /mybots → বট সিলেক্ট → Bot Settings → Group Privacy → Turn off

## লিংক/ফরোয়ার্ড/প্রোমো অটো-মড
গ্রুপে কেউ লিংক, ফরোয়ার্ড মেসেজ, বা প্রোমোশনাল কিওয়ার্ড পাঠালে মেসেজ ডিলিট হবে, ওয়ার্নিং পাবে, ৩টা ওয়ার্নিং হলে অটো ব্যান। গ্রুপ এডমিন ও মেইন ADMIN_ID ছাড় পাবে। নির্দিষ্ট ডোমেইন বাদ দিতে: `/whitelist t.me/yourchannel`। `/ad` থেকে পুরো ফিচার ON/OFF করা যাবে।

⚠️ বট কে অবশ্যই গ্রুপে **Delete Messages** permission সহ Admin বানাতে হবে, নাহলে মেসেজ ডিলিট হবে না (ওয়ার্নিং তবুও দেবে)।

## ব্যবহার সংক্ষেপে
- গ্রুপে: `/warn` (রিপ্লাই দিয়ে), `/ban` (রিপ্লাই দিয়ে)
- প্রাইভেট চ্যাটে বট কে (ADMIN_ID দিয়ে): `/ad` → প্যানেল, `/post` → নতুন চ্যানেল পোস্ট, `/cancel` → চলমান কাজ বাতিল

## ডেটা স্টোরেজ নোট
`data.json` ফাইলে সেভ হয় — Render ফ্রি প্ল্যানে ডিস্ক পার্সিস্টেন্ট না, রিডিপ্লয়ে ডেটা মুছে যেতে পারে। পার্মানেন্ট রাখতে Render Disk অ্যাড করুন বা future এ SQLite/Postgres এ মাইগ্রেট করা যাবে — বললে করে দিব।
